# 使用说明 / Usage

## v0.2.74 停止与后台保存

「停止并保存」接受后会立即隐藏主 HUD 及全部附加面板，停止采样并在后台完成写盘、报告与已提交任务。控制中心会继续显示保存状态，可浏览其他页面；保存期间启动、演示和重复停止按钮禁用，完成后可「重新启动记录」。布局、尺寸、透明度与面板开关不因停止被改写。

没有录到赛事时只提示 HUD 已关闭；保存或报告失败会保留错误状态。存在未保存草稿时继续使用原保护流程，取消停止会保留 HUD 和当前采样。通过独立 HUD 打开的控制中心也能在停止后继续使用并重新启动，退出时一并释放隐藏宿主。

## v0.2.73 图片与 HUD 兼容

图库没有 Ferrari 296 LMGT3 Evo 的独立照片时，纪录详情显示明确匹配的 Ferrari 296 LMGT3 同车系参考图；实际车型名仍为 Evo。其他未知车型不会按品牌随意匹配。

旧布局若将标准预设 640×228 等尺寸保存在纯净模式下，启动时仅在内存中恢复为纯净曲线 440×100、曲线与踏板／方向盘 600×100。已有自定义尺寸保留；新保存的布局携带尺寸所属模式标记，允许有意使用其他尺寸。不会自动覆盖旧布局文件。

赛后先完整保存采样，再独立生成报告。忙时 GUI 保留上一帧并稍后更新，不等待引擎锁；停止时继续等待后台完整保存，但通过定时轮询维持界面响应。最近赛事入口会在后台保存指针后更新。

## v0.2.72 表格阅读与快捷操作

领奖台、纪录履历和官方成绩默认收起筛选面板，直接显示列表；用「筛选条件」展开，按钮上的数字表示已启用条件数。展开状态与筛选内容会在切换页面后保留，收起面板不清除筛选。

赛事、个人纪录及维护列表可用左右键选择当前单元格，黄色细框标记位置；按 F2 打开只读详情，可选取或复制未被省略号截断的完整显示文字。上下键仍选择行，Enter／双击保留原有打开行为。详情绑定打开时的行列与文字快照，再次对另一单元格按 F2 会更新窗口；换页或关闭所属列表后自动关闭。

完整记录管理支持右键和 Shift+F10 菜单。右键已选行保留多选，右键其他行切换到该行；可复制此单元格、复制选中行、查看详情、打开赛事目录或执行原有操作。Ctrl+C 复制选中行，Ctrl+Shift+C 复制当前格；菜单关闭后焦点返回列表。

## v0.2.71 纪录与参赛方式

选中参赛方式未知的个人纪录后，列表旁会出现「标为线上」「标为线下」，点选即可保存；也可用「更正参赛方式」直接选择线上、线下或自动识别。线下沿用历史单人模式的存储值，旧记录仍兼容。确认只影响对应赛事的本机分类，原始赛事文件与官方成绩保留；人工确认会在详情中标明，自动扫描不会覆盖。

赛事复盘的「更多操作 → 更正参赛方式」以及完整记录管理的同名按钮均支持多选。完整记录管理可在「筛选条件」中选择参赛方式未知，然后全选当前列表批量确认。默认「仅更正未知记录」会在保存时重新核对并跳过已知分类，避免覆盖后来识别或人工确认的记录。若需批量撤销人工确认，关闭该开关并选择自动识别。正在记录的赛事和没有本机赛事目录的官方 XML 结果不参与更正。

搜索框可按赛道、车型或日期筛选；空结果可直接清空搜索或重置筛选。列表随窗口高度扩展，顶部「纪录详情」可直达详情，详情操作区可返回原列表位置。

## v0.2.69 界面切换

页面、操作条和返回位置准备好后一起显示。准备较久时显示提示；失败可点「重试当前页面」或从左侧切换页面。赛道指南／车型图鉴顶部固定提供翻页、搜索／筛选和对比入口；Ctrl+F 可定位搜索框，收藏、选择与资料来源保持原有行为。

**v0.2.68：完整记录管理**

**赛事复盘 → 更多操作 → 完整记录管理** 会接住已选赛事，重复打开复用窗口。Ctrl+F 搜索、F5 刷新；赛道 / 车型筛选按需展开，来源筛选始终可用。临时定位不会改写原筛选，可返回原选择与位置。列表上下文在本次运行内保留。

**收藏与标签** 打开绑定具体赛事的多行编辑器；切换列表不会覆盖草稿，关闭或退出可保存、保留草稿、放弃或继续编辑。超过 2000 字会拒绝保存，损坏标记文件保留原文件。

圈速单 / 日志直接使用内置查看器；重新生成、分析、同场提取、1–6 场对比、参考圈、压缩 / 恢复与归档在分组菜单。**导出与参考选项** 可选择 ZIP / 7z、最快 / 稳定圈，以及本窗口本次导入的完整校验。默认快速导入保留；改变显示语言不改变源标识与文件名。

**v0.2.67：辅助窗口与结果反馈**

**最近提取结果** 可多选查看，打开报告、目录或历史对比时需只选一项。顶部显示选择数量，下方说明可用报告与原始频率；原始报告为主操作，120 Hz 报告可用时保留插值精度说明。再次打开已有窗口会刷新列表，也可按 F5；刷新保留搜索、已选结果和滚动，连续刷新会合并。

**报告任务与分步重试** 完成后，在批量窗口选中一项，可打开已有就绪复盘、目录或定位到赛事列表；未就绪报告保持禁用，F5 更新可用状态。批量失败可复制具体原因，无文本异常显示类型名。视频结果和维护列表搜索支持 Enter / 清空即时应用。

**v0.2.66：保存范围与结果衔接**

采样设置的顶部锚点会同步底栏保存范围；有多模块草稿时，可从底栏下拉选择保存对象。底栏提示其他未保存模块数量，Ctrl+S 只保存当前范围。外部生成器的方式 / 路径支持 Ctrl+S，跨页保留草稿，退出时可保存、放弃或取消；失败在表单内显示原因，原配置保留。

赛事复盘和数据页 **更多操作 → 紧凑列布局 / 完整列布局 / 恢复上次列布局** 可切换列视图。既有列偏好不自动覆盖；首次使用默认紧凑布局，完整字段仍在列设置或完整布局中可用。存储页顶部选择按钮可展开 / 收起赛事列表，**查看已选赛事** 可滚动与复制完整身份。

官方遥测导入完成后，选择一项可打开赛事目录或就绪复盘，双击 / Enter 打开就绪复盘，F5 更新结果状态。**在赛事列表定位** 会临时显示该场记录，即便它不符合当前筛选；**返回原筛选** 恢复原选择和位置。输入新搜索或修改筛选会结束临时定位。未就绪复盘保持禁用，可重试失败报告后再打开。

**v0.2.65：紧凑数据页与可恢复设置**

**图像与数据 → 赛事包** 顶部固定导入 / 导出，格式说明与筛选按需展开。切换 **报告与存储** 直接在同一份列表选择赛事，保留已选项目、搜索和列表位置；已选赛事显示日期、赛道与车型，可收起列表。全选 / 清除选择、标签和批量任务在 **更多操作**。

**导入官方遥测** 支持多选 `.duckdb`，沿用批量任务进度、逐项错误与失败重试。报告失败后重试复用已成功导入的数据；源文件只读，仍需先结束游戏中的该次记录。

采样页顶部集中显示练习记录开关、数据接口检查和已保存采样摘要；未应用的采样草稿仍留在表单。赛事包格式、存储及练习记录即时保存失败会恢复原值，显示原因并提供 **重试保存**，损坏配置保留原文件。返回设置页恢复搜索结果，Ctrl+F 聚焦并重开结果；复盘搜索合并连续输入，Enter 和清空即时生效。

**v0.2.38：视频提取与历史圈速对比（实验功能）**

入口为 **图像与数据 → 视频分析与标定**。选择本地视频，填写一圈的开始 / 结束时间、赛道与准确布局，在标定帧中校准油门、刹车圆弧和固定 HUD 文字。按视频条件选择普通 POV、距离与计时 HUD 或同圈遥测；结果单独保存，支持时间曲线、固定地标分段与有条件的距离对比。点击 **对比历史圈速** 可将当前结果或已有 curve.json 与本地已导出的有效历史圈叠加，选择原始 / 游戏过滤后输入；不同布局需重新核对，普通视频不生成距离时间差。详细步骤、外部工具要求与数据精度限制见 [视频分析](VIDEO_ANALYSIS.md)。

**v0.2.33：报告恢复、训练跟进与缓存管理**

- **图像与数据 → 报告任务与分步重试**：查看每场报告的状态与未完成步骤。停止 HUD、等待后台任务完成后多选重试；已成功且未受影响的步骤保持原样。错误和重试前的输出保存在赛事内 `_report_history`，原始 CSV 保留；不会自动重做全部历史报告。
- **训练优先级报告 / 同条件进步分析 → 分析范围**：默认只比较相同参赛方式、阶段、布局和车型，且条件已知的有效圈。可展开探索选项纳入未知条件或跨阶段 / 跨参赛方式；此类样本标明探索，不计入可靠进步结论。每场至少 3 个有效圈才能评价波动。
- **训练优先级报告 → 选择区间 → 设为本次训练目标**：保存该区间、实际参考圈及基准。下一场记录结束后，在 **个人赛道纪录 → 训练目标跟进** 或报告内查看新增赛事的典型区间损失、波动和样本数。只有建立目标后开始的新赛事参与；基准和新样本均足够且条件明确时才显示提升值。结束目标保留其文件，不删除基准。
- **官方战绩 → 成绩冲突对照**：分别显示遥测末次观测与官方结果，列出 XML 路径、时间和遥测记录区间；仅供核对，不自动选定或覆盖结果。
- **图像与数据 → 缓存与导出文件**：先查看占用。停止 HUD 并等后台任务结束后，可清理训练曲线缓存、派生最快圈缓存和赛事摘要索引，之后按需重建。原始赛事、导出图片 / HTML、训练目标、标签与常用视图不可在此处删除。

分析缓存和新图片报告复用以文件尺寸与修改时间识别变化，不进行 SHA-256 内容校验。燃油预测约每秒更新 10 次，关键状态变化立即刷新；原始遥测继续按既定频率采集。本轮保留转向角显示。

控制中心右上角 **浅色主题 / 深色主题** 可即时切换两套终末地风格配色，选择保存在 `data/interface_settings.json`。切换保留当前页面、搜索、赛事选择与表单；已经启动的 HUD 继续采集。纯净 HUD 保持全黑背景，油门绿 / 刹车红 / 转向蓝的含义不变，浅色界面使用更深的色调保证可读性。新生成的 Review 和圈速对比 HTML 也提供主题切换，导出后仍可离线使用；历史 HTML 保留原样。

赛事列表按像素平滑滚动；鼠标进入列表时滚动记录，移到面板其他区域滚动页面。跨赛事对比支持 Ctrl 多选、Shift 范围选择，方向键 / Home / End / PageUp / PageDown 浏览，Enter 或双击打开复盘；Shift＋滚轮横向查看长列。动画只在交互时运行。

1. 把解压目录放在普通可写文件夹。源码运行 `Setup.cmd`；便携包直接双击 `LMU-Stintrix.exe`。
2. 在控制中心的 **运行与 HUD** 点击 **启动 HUD**，再进入 LMU 驾驶会话。排位赛 / 正赛显示 REC 并自动记录；**采样与遥测 → 记录练习赛** 可开启练习录制，默认关闭，保存于 `data/recording_settings.json`，重启后保留。运行 HUD 时成功保存的切换立即生效；关闭会先完整保存当前练习记录。Warmup 只显示实时曲线。结束会话或正常退出 HUD 时完成保存与分析。
3. 控制中心按功能分成七页，**赛事复盘** 合并圈速对比，共用一份赛事列表。HUD 标题栏菜单按钮可返回控制中心，右键快捷菜单保留。停止 HUD 后仍能查看报告；关闭控制中心会先等待录制与后台任务完成。
4. **赛事复盘 → 圈 A / 圈 B 选择器** 中分别选择赛事和圈号，支持同场或跨场任意两圈与不同车型。仅列出已验证的有效完整圈，排除进站、无效、缺边界、遥测断层、重复圈号或未验证旧圈。两个布局名都存在时必须一致，同时赛道名相同、实测长度差不超过 1 m。源文件不改写，提取保存至赛事内 `SelectedLaps`，对比页保存在 `data/LapComparisons`。会话库的旧完整圈提取器仍允许带标记的圈用于查看。
5. HTML 报告可以离线打开；拖动播放时间查看曲线和轨迹。赛道区域用滚轮缩放、拖动平移、重置回到全图。不同车辆、天气、燃油、轮胎差异会影响结论；驾驶建议仍要求同车和相近条件。
6. 原生 LMU 记录可从菜单导入或运行 `Start.cmd --import-duckdb "完整文件路径"`；源数据库只读，生成文件保存在 `data/ImportedLogs/`。先等待游戏关闭并结束该记录。
7. 在 **比赛记录管理** 中按 Ctrl / Shift 多选记录，点击 **导出比赛包（可多选）** 并选目标目录；每场按所选格式生成 `.stintrix.zip` 或 `.stintrix.7z`。把这些包上传网盘即可。下载后点击 **导入比赛包（可多选）**，选择一个或多个 ZIP / 7z，程序默认快速导入并加入 `ImportedLogs`，无需手动解压或重新生成报告。

**个人赛道纪录** 按赛道名、布局名、记录长度与车辆组别分开统计。详情突出圈速，车型与日期独立显示；**赛道条件** 展示布局/长度、赛道温度、气温、路面湿度和降雨，**车辆与轮胎** 展示油量、前后胎种、最低已记录轮胎余量及 TC/ABS。轮胎不展开逐轮胎温和胎压；点击 **打开完整圈曲线** 查看全分辨率数据、速度、轨迹与详细车辆遥测。缺失条件显示未知，只有胎种编号时保留编号，不推断软硬。演示记录与未验证旧圈不参与；没有可信有效圈的赛道不生成纪录。

所有赛道纪录均显示 **布局名称 · 长度**，包括大奖赛、国际、短布局、减速弯 / 无减速弯等；不同布局即使长度相同也分开统计。未识别的布局保留游戏原名，旧记录缺失布局时显示“布局未记录”，不根据圈速推断。原始赛道 / 布局字段不翻译、不改写。

最快圈与同组领奖台的详情右上角展示对应车型图鉴照片，切换纪录时同步更换；窄窗口自动放到文字下方。图片代表车型，涂装不保证与当场车队相同；没有匹配车型素材时不显示其他车辆。

赛事资料库支持按 UTC 时间范围、开始 / 结束日期、阶段、赛道和车辆组合筛选；结束日期包含当天。排序可选时间、阶段、赛道或车辆的升序 / 降序，排序保持选中赛事身份不变。下拉选择立即应用，日期可按 Enter 或点击“应用筛选”；“重置筛选”恢复全部记录和最新优先。顶部文字搜索仍可叠加使用。

同一菜单内可切换 **赛道最快圈 / 同组领奖台**。领奖台按冠军、亚军、季军分类，保留每场已确认正常完赛且同组名次为 P1–P3 的正赛；排位、练习、退赛、取消资格、演示和缺少同组完赛结果的旧记录不计入。重复导入的同场赛事只展示一次，结果冲突时提示并排除；读取页面不改写历史记录。

领奖台详情分区展示 UTC 比赛时间、总 / 同组发车与完赛位置、车型 / 车队 / 类别、个人有效最快圈、赛道布局与长度、赛道条件及车辆条件起点 → 终点。轮胎保留前后胎种和最低余量，不堆叠逐轮胎温胎压。比赛进程提供圈速随记录时间的曲线，以及覆盖全场已记录区间的油门 / 刹车缩略曲线。**比赛用时** 仅在记录包含绿旗和正常完赛时显示；中途开始录制时保留已记录时长并提示缺失，未知数据不补造。可打开原赛事复盘或目录查看完整资料。

中文模式显示中文赛道名，中英文均可搜索；英文模式显示原名。布局名等于赛道名时只显示长度，避免同一名字重复两遍。翻译只作用于菜单显示，不改写记录、文件名或同布局对比身份。

个人纪录统一 LMU 组别别名：游戏计分中的 GT3 与旧记录的 LMGT3 同为 LMGT3；LMH/LMDH 合并为 Hypercar，GTE、LMP2 等组别继续分开。只改变统计分组，不改原始元数据；同组重复项保留更快的有效圈。

新记录的比赛日志在原“发车”和“完赛”卡片中并列显示总排名与同组排名，例如 `P32 / 同组 P14`。历史记录保持旧样式；新记录缺少同组计分时显示“同组 未知”。DNF/DQ 保留退赛状态，不将末次观测当作完赛排名。比赛日志不再追加独立的顶部组内排名面板。


缺少最快圈报告的已完成赛事会在后台从原始采样提取有效最快圈，缓存只写入 `data/PersonalRecords/Cache`，原始赛事不变。已有报告优先读取摘要；曲线按选择加载，完整遥测与数值精度保留。

**赛事复盘** 的 **全选当前列表 / 清除选择** 位于顶部 **更多操作**；全选只选择当前搜索和筛选结果。

在 **图像与数据** 选择用户自有 RaceCom 的 **Image Generate.exe** 并保存配置，保留其旁边的 `Source` 图片目录。赛后程序自动在后台调用它，使用原版浅色版式生成 `圈速单.png` 和 `比赛日志.png`，连同 Stintrix 完整 JSON / TXT 保存在同场 `data/Logs/日期时间_阶段_赛道/`。原版输入适配文件保存在该场 `_racecom/`；比赛包自动包含报告。没有完成圈时只生成比赛日志。

公开下载包未附带 RaceCom 程序或车型照片。未配置时赛事仍保存，并提示配置；不会默默使用不同版式。`native` 是明确可选的 Stintrix 兼容版式，宽 1800 像素、36 条分页；演示模式使用兼容版式。切换生成方式会将已有报告备份到 `_report_history/`。原版中 PIT、部分记录和有效性未验证的圈标为 **统计无效**，仅排除最快圈统计，不代表游戏处罚。

新记录的 `race_events.csv` 只保存变化事件，不扩充高频输入 CSV。记录官方圈号、圈速和 S1 / S2 / S3、观测名次、进站、待执行处罚数量变化、无效圈、碰撞和赛事阶段；出界是车体位置相对于游戏近似赛道边界的持续越界估算，**不是 Race Control 的官方警告**。连续碰撞接触会合并。未观测发车格时显示首次观测名次；DNF / DQ、手动退出和中断恢复会区分。进站圈、部分记录和无效圈不作为个人最快圈。

旧赛事选中后点击 **圈速单 / 比赛日志** 即可补图并打开目录；已有 PNG 损坏时也可重新生成。不改写原始 CSV、元数据或圈文件。旧记录无法追溯当时未采集的分段、名次与碰撞，显示未知。也可运行 `Start.cmd --race-images "完整赛事目录路径"`，正在录制的场次不能补图。生成失败时查看同目录 `race_images_error.txt`。

车辆图片可选，公开版不附带第三方车型照片。自己有使用权的图片和校准文件可放在 `data/assets/cars/`；沿用 RaceCom 的 `car_calibration.json` 结构：`cars` 映射图片文件名到 `aliases`（车型别名列表）和 `subject_bounds`（0..1 范围的左、上、右、下）。支持 PNG / JPG；按完整车型和显式别名匹配，不猜测同品牌车型。图片按校准范围留边、保持比例放入卡片，原图保留。没有图片时仍生成完整两张图，以车型文字代替。

新录制文件夹按 `日期时间_Practice/Qualify/Race_赛道名` 命名，导出比赛包名称也包含阶段。阶段读取 LMU 的 `mSession`：测试日与练习显示 `Practice`，排位显示 `Qualify`，正赛显示 `Race`，暖胎会话单独显示 `Warmup`。比赛记录管理新增“阶段”列，可在搜索栏输入这些英文标签筛选。旧文件夹无需改名，已有阶段编号的旧记录会直接显示标签；缺少阶段信息的记录（包括当前原生 DuckDB 导入）显示 `Unknown`。

在 **图像与数据 → 赛事包** 点击各行左侧复选框可选择多场赛事；表头复选框或 **更多操作 → 全选当前列表** 选择所有搜索结果，**清除选择** 取消选择。Ctrl / Shift 多选与空格切换当前行也可用。点击顶部 **导出赛事包**，只选一次目标目录，每场按导出格式独立生成一个 `.stintrix.zip` 或 `.stintrix.7z`。后台逐场处理，失败的场次单独提示，其他赛事继续导出；批量任务保留进度和失败重试。

比赛包包含该场文件夹内全部已完成文件，包括原始 CSV、附加 / 原生遥测、离线网页及其嵌入底图、最快 / 稳定圈、圈 A / B 提取目录，以及记录管理的备注和交通标记。临时写入文件、机器设置、其他比赛与全局底图库不打包；原始文件逐字节保留。比赛包包含车手姓名、圈速等个人数据，应作为私人网盘文件保管，Git 会忽略 ZIP 和 7z。

导出与导入在后台流式处理，不把整场装进内存。当前 v2 清单不存储或核对内容 SHA256；旧 v1 清单继续支持读取，但旧“完整校验”参数不重新启用内容扫描。相同包按本机收据与元数据复用结果，不覆盖原赛事，也不表示通过完整性认证。仍保留路径安全、大小上限、基本格式与正常解压检查。批量中的坏包单独报错，其他包继续处理。正在录制的场次不能导出，中断记录请先恢复。只支持本功能导出的 Stintrix 比赛包；普通压缩包和软件发布 ZIP 不能当比赛包导入。新 v2 比赛包需 v0.2.40 或更新版本直接导入，旧 v1 包继续兼容。当前每包支持最多 50000 个文件、展开后 32 GiB。详见[无损存储与归档](STORAGE_OPTIMIZATION.md)。

快捷入口：`Demo.cmd` 使用合成数据；`Start.cmd --clean` 只显示曲线；`Start.cmd --clean-controls` 同时显示曲线、柱形图和方向盘。

默认 120 Hz。设置中的 1–4000 Hz 是目标轮询 / 绘制频率，动态模式可设最小 / 最大频率和变化阈值。实际新数据速率不会超过 LMU 的提供频率；高设置也受 CPU、显示器和 Windows 定时器限制。诊断窗口可查看实际速率、错过周期、队列和记录状态。不要把重复读取次数当成新的物理采样。

发现不到游戏目录时，仍可直接读取共享内存；目录只用于原生记录文件选择的起始位置。源码可运行 `Setup.cmd -GameDirectory "你的游戏目录"`；便携包可在根目录创建 `local_settings.json`：

```json
{"data_directory":"data","game_directory":""}
```

也可用 `LMU_STINTRIX_DATA_DIR` 环境变量指定私有数据目录。不要指向游戏安装目录或公开源码目录。现有设置保留，Setup 不覆盖用户采样偏好。

打不开 HUD 时查看 `data/startup_error.log`；源码版可运行 `tools/Check.cmd` 检查开发环境。便携包不附带自检和测试程序。打不开地图时检查记录是否具有世界坐标 / GPS。独占全屏请改为无边框窗口。此工具不提供游戏控制或输入注入。

## 赛道指南与车型图鉴

从左侧进入赛道指南或车型图鉴，图片、详细说明、练习建议和来源均在程序菜单内呈现，无需浏览器、GTD 或服务器。每行一张宽松卡片，每页最多 3 张，使用顶部或底部的上一页 / 下一页；推荐车型和车型关联赛道可以展开 / 收起。

支持中英切换、组别 / 车型 / 收藏筛选、中文赛道别名搜索、收藏与 2–3 项原生对比。点击加入对比后，在上方的选择区点击查看对比；对比卡片保留赛道上下文，在同一菜单内分为 A / B / C，仍以单列展示保证可读性。来源链接默认折叠，点击“来源链接”展开，再点击可收起；展开后可复制，不自动跳转浏览器。切换主题或语言时保留已展开状态。

资料仍采用 GTD `2026.09.22.1` 快照，保留原日期、V1.4.2 参考版本与未验证标记。文字、42 张官方来源图片和全部 144 条推荐随便携版打包。Pillow 仅用于本地图片解码与菜单标识缩放，不访问网络，不接入实时遥测。

## Windows 快捷启动与表单操作

控制中心 **运行与 HUD → Windows 快捷启动 → 添加 / 更新开始菜单** 会创建当前用户的 `LMU Stintrix` 快捷方式。程序会核验 Windows 应用目录，确认识别后可在 Windows 搜索中输入 `Stintrix` 或 `LMU`，也可从开始菜单的所有应用启动；无需管理员权限。可右键搜索结果固定到开始菜单或任务栏。移动便携文件夹后，重新打开 EXE 点击更新入口即可；移除入口不会删除程序或个人数据。首次解压仍需保留完整 `_internal` 文件夹。

表单使用统一的切角输入框与下拉面板：黄绿焦点描边、短展开过渡、平滑选项高亮，兼容深浅主题。下拉框支持方向键、Home / End、输入前缀跳转、Enter 确认、Escape 取消和 Tab 切换；长列表可滚动。动画仅在交互时运行，离开页面会清理弹层与回调。

已启用的入口在新版启动时会按当前登录用户检查并修复；检查在后台进行。若显示“Windows 尚未列出应用”，可稍后再次点击更新。入口识别状态保存在本机 `data/desktop_registration.json`，不参与发布。

控制中心顶部 **EN / 中文** 可切换整个菜单语言，重启后保留；主题和语言分别保存到本机 `data/interface_settings.json`。赛道指南与车型图鉴随菜单语言切换，赛事记录、配置值和文件名不因语言切换而改变。

左侧切换先清除旧内容，再呈现新页面；采用短强调条动画与分批构建，连续点击以最后一次选择为准；运行与 HUD、采样与遥测两个常用页复用，来回切页时保留未保存输入。其余页面离开即释放，指南图片在后台解码，仅在可视区域创建 Tk 图像。切换主题 / 语言仍重新构建页面，请先保存表单改动。

赛事复盘中选中一场记录，点击 **删除选中赛事**。确认提示显示日期、阶段、赛道与车辆；默认取消，确认后直接从本机永久删除该场文件夹，包括完整遥测、圈文件、报告与关联备注，释放磁盘空间，不保留回收副本。无法撤销，需要留档时请先导出赛事包。正在录制、写盘异常或后台处理尚未完成时不能删除。操作只针对当前数据目录下所选的一场记录，不修改其他赛事、采样设置或游戏文件。


赛事复盘支持勾选多场、全选当前筛选结果和清空选择。点击删除后核对数量和赛事列表，确认后直接永久删除；录制中记录不能删除。查看单场 Review、圈速单、比赛日志和圈 A/B 时只选择一场。

地图自动校正实测坐标的镜像，旋转按钮可调整朝向，轮廓、回放车辆和点击定位同步变化。地图轮廓估算继续标记为估算，不会转换为实测。旧报告的地图显示可在源码目录运行 tools/upgrade_maps.py 升级；仅替换地图渲染器，CSV、圈 JSON、赛事元数据和 HTML 嵌入记录保留。


低内存时，原始记录仍正常写盘，赛后报告可能稍后生成。可用提交内存低于 512 MiB 或可用物理内存低于 256 MiB 时，程序保存 report_pending.json；运行中的菜单 / HUD 每 5 秒检查重试，退出后的待处理记录也会在下一次启动后继续。录制已经完成，无需重新比赛。

便携版的分析使用临时磁盘文件和低优先级后台进程，进程完成后释放内存。高频完整圈可能需要更长时间生成报告；采样率、HUD 绘制频率、原始 / 过滤通道、圈比较与图像版式保持原设置。临时文件放在当前记录目录所在磁盘，结束后自动清理。源码可通过 make_report(folder, isolated=True) 使用相同的进程隔离。


## 无损减少存储空间

可重建训练与最快圈缓存默认合计 512 MiB，可在此页调整；“缓存与导出文件 → 按上限整理”可立即整理。仅程序生成缓存可淘汰，用户导出和正在使用的缓存保留。

在 **图像与数据 → 无损节省磁盘空间** 可启用或关闭赛后自动压缩，也可先在赛事列表勾选多场，点击 **压缩选中赛事**。默认开启，只有完整记录且所有报告生成阶段结束后才进行；录制采样线程不执行压缩。原 RaceCom 图片保留原版图像字节，PNG / JPEG / WebP 不重复压缩。

新赛事默认在赛后转为 `.csv.stc` 无损分块列式文件，插件透明读取，完整采样和精度保留；报告等文本继续使用 Windows NTFS 每文件 LZX。v0.2.41 增加更紧凑的编码并使用 STC v2，仍支持读取旧 STC；旧版插件读取新 STC 前须先用新版恢复 CSV。历史 CSV 不自动迁移。可使用“转换选中赛事为列式”，或“恢复选中赛事为 CSV”供旧版 / 外部工具直接读取。“导出原始 CSV”保存到独立目录；“导出独立复盘页”生成可单文件分享的 HTML。

压缩逐文件记录逻辑大小、修改时间与实际占用至本场 storage_compression.json，不执行 SHA-256 内容校验。Windows 文件属性中的“大小”仍是原始逻辑大小，“占用空间”才反映节省；界面 MB 大小字段仍表示原始 CSV 大小。重复压缩仅处理当前文件，不生成额外完整副本。空间节省随记录内容变化，失败项会记入收据；压缩失败不影响已保存比赛记录。平直输入与无损编码的区别见 [无损存储说明](STORAGE_OPTIMIZATION.md)。

压缩开关保存在本机 data/storage_settings.json，默认启用；此设置、赛事收据及个人记录均不进入发布包。报告或完整曲线的离线处理可能比一次性加载稍慢，以换取较低峰值内存；输入精度、全量样本、事件和各通道的频率保留原样。实时 HUD 刷新与采样设置不改变。


7z 导出使用官方精简工具 7zr 26.04，独立低优先级进程、单线程、8 MiB 字典和独立文件块。已转换的列式采样在临时目录展开为普通 CSV，其余原文件尽量通过硬链接读取，完成后移除临时内容。ZIP 直接流式还原 CSV。新导出不计算文件内容哈希、不完整回读校验；归档格式自身的正常解码与安全路径处理保留。重复导出未变化赛事复用同目录的既有包。

便携版已包含约 0.6 MB 的工具，不要求安装 7-Zip。源码首次 Setup.cmd 从官方 GitHub 下载固定版本并核对固定 SHA256；工具缓存、赛事包选项 archive_settings.json 和个人包均不会上传源码仓库。菜单默认 ZIP 导出，选项修改后保存；中英文和两个主题共用设置。


## 训练报告、战绩卡与纪录履历

**个人赛道纪录 → 赛道最快圈**：选择一条纪录，在详情底部点击 **训练优先级报告**。程序在后台读取同车型、同布局的历史有效完整圈，按条件匹配后使用真实最快圈作参考，至少需要 4 圈（参考圈加 3 个比较圈）。首次分析完整 CSV 可能需要几分钟，后续读取私人缓存；数据变化会重算。窗口可查看典型时间差、波动和输入差异，并导出完整离线 HTML，保存在数据目录 `PersonalRecords/TrainingReports`。

训练区间由参考圈制动输入划分，无明显制动时使用等距离区间；不代表赛道官方弯号。排序分数为 `max(0, 时间差中位数) + 0.25 × 时间差标准差`，只帮助选择练习顺序，不是预测可提升时间。缺失条件标注未知，无法证明同条件；报告同时列出不完整 / 无效圈、条件差异和读取失败。输入曲线用于统计的距离采样为 601 点，原始记录和完整曲线保留。

最快圈详情、同组领奖台详情或 **纪录履历** 里点击 **生成个人战绩卡**。默认不展示姓名与日期，按需勾选后点击 **生成并打开图片**。输出 1920 × 1080 PNG，保存在数据目录 `PersonalRecords/AchievementCards`；包含对应车型图片和主要成绩、燃油、胎种、赛道条件。每次使用独立文件名，旧图片不覆盖，图片不自动上传。

**纪录履历** 是最快圈与领奖台的第三个并列页。每条布局 / 长度 / 组别分别按赛事时间统计首次记录和实际提升，可打开对应完整圈曲线、源赛事目录或生成战绩卡。由每场已保存的最快圈重建，未保存的逐圈刷新过程无法还原；日期缺失、冲突副本会明确显示排除数量。同一时间戳不能确定先后时只保留其中最快的观测。


### v0.2.23 纪录分类与战绩卡预览

纪录履历默认从新到旧，可组合筛选赛道、车辆、布局 / 组别，排序支持最早优先、按赛道分类、按车辆分类。此页的刷新纪录按车型分别统计，因此某车被同组更快车型超过后，仍可保留该车自己的进步；赛道最快圈页仍按车辆组别统计。

## 官方战绩与四项分析功能（0.2.29）

1. **采样与遥测 → 数据接口检查**：游戏关闭时等待共享内存是正常状态。SDK 声明存在只证明接口可发现，不证明所有通道已通过实机验收；新录制保存接口版本信息，旧记录不改写。
2. **个人赛道纪录 → 官方战绩**：填写多人赛事车手姓名（不填则采用本机已记录姓名），点击同步游戏成绩，或选择 `UserData/Log/Results` 文件夹。默认最新优先；可搜索并筛选阶段。多人 XML 的 `isPlayer` 表示真人，不一定是本机玩家，因此身份不明确时不自动选人。`Practice1` 等带编号阶段也支持。
3. 游戏 XML 的 `ClassPosition` 明确、正常完赛且同组前三时可补充领奖台。与遥测冲突或关联不明确的结果不会领奖；原始 XML、旧 PNG / HTML 均不改写。只有 XML 的赛事显示官方圈计时，无法展示油刹、油量或天气曲线，也不会进入有效完整圈纪录。`FinishTime` 起跑基准未确认，不能直接视为真实比赛用时。
4. **赛道最快圈 → 训练优先级报告**：至少 4 个同布局、同车型且条件接近的有效圈，以实际最快参考圈分析。图中点击区间选择数据；可编辑距离区间并重新分析。坐标缺失或无有效运动时使用距离条。滑行为油门、刹车均低于 3%；ABS/TC 是实测触发时间，覆盖不足显示未知。导出 HTML 包含轨迹 / 距离分段图和完整表格。
5. **赛道最快圈 / 纪录履历 → 同条件进步分析**：默认油量 ±2 L、气温和赛道温度 ±5 °C、湿度 ±0.1、雨强 ±0.05，胎种、抓地与 TC/ABS 一致。每场至少 3 个有效圈才评价稳定性，至少两场条件已知且样本足够的赛事才描述长期变化。探索模式允许查看未知条件，仍不纳入可靠结论。显示实测中位数、最快圈与标准差，不进行油量修正或驾驶提升归因。

所有同步、诊断、自定义区间、分析和导出均保存在本机 `data`。缓存根据路径 / 大小 / 修改时间复用；统计先加载轻量索引，完整曲线逐场读取。新增流程不计算文件哈希；首次分析较慢，缓存后重复分析可复用结果。结果同步由按钮触发，无后台持续扫描。

共享内存恢复稳定双快照轮询，仅读取通知对象是否存在，不消费游戏事件。短暂断流或冻结不切分同场赛事，恢复后继续写入原记录；缺失采样不会补造。明确阶段改变、会话时间重置、完赛、离开实时会话或正常关闭仍结束记录。


### 0.2.31：车库续录与参赛方式

进站、车库、暂停或离开驾驶画面不会单凭实时状态结束记录；恢复驾驶后写入同场 CSV，空白时间不补造采样。真正阶段 / 评分会话计时改变、完赛、手动停止与关闭程序仍结束记录。

赛事复盘和个人纪录各标签提供参赛方式列、全部 / 单人 / 线上 / 未知筛选及单人优先 / 线上优先排序。最快圈筛选在选择胜出圈之前进行，线上较慢纪录不会被单人成绩遮住。履历进步曲线不连接不同参赛方式。

历史标记来自匹配的游戏结果 XML：Multiplayer 为线上，Race Weekend 为单人。匹配要求车手、车型、赛道布局、阶段与会话起点一致；不能确认时显示未知。新录制的 SDK 客户端状态可证明线上；服务器 / 本地宿主状态不单独推断。模式索引保存在 `data/RaceModes`，不改写旧 session / CSV / PNG。可在官方战绩手动同步；已有结果源的目录发生变化后，刷新列表会复用缓存更新标记。

已有错误切分可通过本机 `data/SessionGroups` 索引归并展示。原片段不删除、不改写；合并记录完整且有原件来源时才隐藏片段，合并记录不可用时原片段重新可见。合并仅拼接现有采样并重算相对时间，缺失区间不补造。


## 赛事筛选、常用视图与数据依据（v0.2.32）

赛事复盘与个人赛道纪录下的最快圈、领奖台、履历、官方战绩使用同一套筛选。基础区选择赛道、具体布局、组别与车型，工具条切换排序与常用视图；展开“高级筛选”可按阶段、参赛方式、时间、车队、成绩、成绩依据、数据质量、标签、收藏、可用数据与条件范围继续缩小。

- 基础条件组合为 AND；空范围不限制。日期按 UTC，结束日期包含当天。数字范围上下限均包含边界，油量单位 L、温度 °C、比赛时长单位分钟。缺失条件不会作为 0 或干地匹配。
- 天气与车辆条件来自已记录有效圈；旧分析缺失时只用已保存最快圈条件，选中行会标明范围。最快圈和履历按该候选圈的条件筛选。混合天气只在实际观察到干湿两种条件时标记，不代表整场覆盖完整。胎种使用原始名称，不跨车型猜测胎种编号。
- “官方确认”来自无冲突的官方 XML 关联，“遥测确认”要求明确结束标志。“末次观测”仅代表最后看到的排名。DNF / DQ 不作为正常完赛排名或领奖台，缺发车名次不计算净提升。XML 的 FinishTime 基准未确认，不直接作为比赛用时。
- 数据质量“有有效完整圈”只确认至少有一圈通过校验，不表示整场无缺口。旧记录没有断流标记时，缺口数量保持未知。“未标记交通影响”不代表无交通。
- “保存视图”保存当前筛选、排序与搜索文字；内置视图含线上 LMGT3 正赛、同组领奖台、采样缺口待检查与收藏赛事。自定义视图可删除。条件标签右侧 × 只清除对应条件，“重置筛选”同时清空搜索。
- “收藏与标签”将个人标记保存到本机注释文件，不写入原始赛事元数据。记录管理窗口修改旧备注也会保留已有收藏、标签。
- “检查疑似拆分”只列出相同身份、相邻且前段未确认结束的正赛片段，供分别打开复盘检查；它不判断一定同场，不自动合并或删除。标为已检查只隐藏该候选提示。

私有索引位于 `data/EventCatalog/index.json`，视图位于同目录 `views.json`；文件变化时增量更新。索引不加载原始 CSV，也不计算文件内容校验和。索引可删除后重建；个人标签、视图和已检查标记需另行保留。

## 静默记录与赛事成绩

在 **运行与 HUD** 开启 **静默记录 · 隐藏全部 HUD**，再点击 **启动记录**。也可以在记录过程中切换：主输入 HUD 及轮胎、策略、进站、Stint、天气 HUD 一起隐藏，采样与记录不会中断。关闭开关恢复此前启用的 HUD，不会重置各面板设置。开关会保存到本机，下次启动仍生效；停止与保存仍在控制中心操作。排位与正赛自动记录，练习赛沿用原有记录设置，静默模式不会改变记录范围。

赛事复盘列表的 **完赛名次** 仅显示已确认的同组正赛／排位成绩（P1、P2…）或 DNF、DQ；未知、冲突或只有末次观测排名时显示“—”，不使用总排名代替同组成绩。个人赛道纪录页的 **领奖台记录** 仍只收录已确认同组完赛前三的正赛，统计规则不变。


设置页未保存的修改会显示提示，并在切换语言及页面重建时保留；点击「应用并保存」后才更新配置。视频结果可通过「图像与数据 → 最近提取结果」重新打开。

### v0.2.50：HUD 布局、回退与快捷操作

在「运行与 HUD」点击 **HUD 布局与备份**：

1. 已启动 HUD 时，可先拖动窗口再点「读取当前 HUD」；未启动时也可直接编辑面板数值。
2. 填写布局名称，逐个选择面板，设置位置、大小、透明度、显隐及整体显示模式，点「保存并应用」。选择框只载入编辑区；「应用所选布局」才会切换画面。

4. 切换、覆盖、删除和恢复前自动备份，也可点「备份当前 HUD」。备份下拉框保留最近 12 次，时间标为 UTC。恢复会还原当时的布局列表、当前方案及画面，恢复前的状态也会再留一份备份。

运行页显示实际下次启动的配置。待机时更改显示模式、波形窗口或面板显隐，会更新下次启动的显示状态；已命名的预设仍保留原值，可重新应用。静默记录仍优先隐藏所有 HUD。

- 布局、快捷键和列设置窗口使用明确按钮处理未保存修改。「继续编辑」保留窗口，「保留草稿并关闭」仅保留到本次程序退出前；关闭主控制中心时，会检查这些编辑器和保留草稿，退出时需保存或明确放弃。快捷键异步保存失败、或保存期间又有新修改时，窗口保持打开。
- 列设置按「列名称／显示／固定」排列。隐藏列后固定开关不可操作；重新显示仍可调整。恢复默认列先填入草稿，点击「应用并记住」才会改动表格。
- 采样、车辆策略、耐力设置以及布局、轮胎阈值的错误会标到对应字段。保存失败时可直接修改标记字段，数值范围和有效输入的保存含义保持原样。
- 设置页顶部支持搜索，Ctrl+F 聚焦；输入名称、英文或原参数名后，Enter 定位第一项，↓ 可进入结果按钮。「胎压」可打开对应阈值字段，「透明度」可定位布局中的不透明度输入框。
- 赛事表格被省略的文字可悬停查看。Ctrl+C 复制选中行的显示列（含标题），Ctrl+Shift+C 复制当前单元格；点击单元格确定当前列，键盘移动可切换当前行。赛事复盘右键菜单在选中记录后也提供复制操作。复制不会改变选择、筛选或原始数据。
- 布局预览内滚轮以指针为中心缩放，中键或拖动空白处平移；「适合全部显示器」恢复全图并重新读取显示器范围，「聚焦所选面板」放大当前编辑对象。缩放和平移不改变草稿坐标，也不会移动实际 HUD。

### v0.2.53 操作闭环

- 退出控制中心前检查普通参数草稿；选择保存时先验证全部修改。写入失败会留在程序内，已保存模块和未完成模块分别保留实际状态，不宣称多文件事务回滚。车型阈值切换和关闭也有草稿保护，保存按钮固定在底部。
- 采样页会标出仅动态采样、固定采样或手动刷新时生效的参数。提示不修改数值；灰显字段仍可编辑修正，无效值仍按原边界校验。
- 赛事包导入、批量导出、压缩和存储转换在任务窗口中显示当前项及逐项结果。「当前项完成后停止」不会中断正在写入的文件；之后可继续剩余项或仅重试失败项。关闭任务窗口只隐藏，可从「图像与数据 → 赛事包 → 批量任务与失败重试」重开。任务历史的保留规则见下方 v0.2.54 说明。
- 赛事表头的时间、阶段、赛道、车辆、参赛方式、圈速和同组名次可切换现有排序；箭头表示当前排序，选择保持。双击列边界按当前列表内容调整列宽，仍可手动拖动。原排序编号不变，圈速和同组名次的反向排序追加在末尾。
- 空列表区分加载、无记录、筛选无结果和失败；按钮分别导入、清除搜索与筛选、重新加载。
- 设置搜索结果采用紧凑双列，长名称省略时悬停或键盘聚焦可读全名；新增练习赛记录、静默记录、存储、缓存、生成方式和全局快捷键定位入口。
- 视频提取中关闭窗口，可选择后台继续处理；从视频分析入口可重开同一窗口。取消后会等待处理返回，再处理关闭。未保存标定可单独保存 calibration.json，包含部分圆弧点、圈段、身份、地标和同步文本；加载后仍需读取预览核对分辨率与HUD。此文件只保存本机，不代表完整圈提取成功。

### v0.2.54 常用操作

- A/B 窗口可分别选择最快有效圈或交换两侧。选择同一圈、不同布局或缺少可靠长度时会提前提示；最终仍执行原有完整圈校验。
- 备注可多行输入，最多2000字；标签最多20个，每个40字，超限时保留原输入并提示修改，不会静默截断。关闭可选择保留本次运行草稿；重新打开同场赛事继续编辑。
- 批量窗口顶部可切换本次运行的任务清单。未完成/失败任务保留；新的任务只淘汰较早的成功清单，保留最近5份完成清单。重试历史任务与新建任务不能同时执行文件操作。程序退出后清单不保留，输出文件仍在原目录。
- 编辑参数后底部显示固定保存区。点击字段决定当前模块，Ctrl+S或「保存本模块」只保存该模块；「撤销本次修改」重新读取其已保存值，不写磁盘，不影响其他模块草稿。
- 资料页的 Ctrl+F 聚焦搜索，Esc和清除按钮只清空搜索文字。最近提取结果选中后可直接「与历史圈对比」，不必重新挑选 curve.json。
- 删除确认统一显示目标摘要和明确动作；仍只进行一次删除确认，默认焦点为取消。布局删除的自动备份恢复、赛事删除的永久性均与原规则相同。

### v0.2.55 查找与结果切换

- 圈 A / 圈 B 顶部可搜索赛道、时间、车型等多个关键词。Ctrl+F 聚焦，Esc 或右端清除按钮清空。筛选仅缩小两个赛事下拉列表，不自动改变当前已选赛事或圈次。
- 批量任务可按全部、失败 / 部分失败、未完成查看，并搜索文件名或错误。「仅重试失败项」仍重试整份任务清单的全部失败项；「复制全部失败详情」也包含被筛选隐藏的失败项。
- 最近提取结果使用相同搜索操作。当前结果被筛选隐藏时，报告按钮禁用；清空后恢复原选择。Enter / 双击优先打开原始报告，没有原始报告时打开现存的 120 Hz 报告；120 Hz 仍是估算插值，不增加视频原始精度。
- 历史圈对比顶部显示当前视频结果。已有对比窗口时，从最近结果选择另一文件会切换到该文件；若有未生成的设置，先选择放弃或继续编辑。处理中不会切换输入；未生成设置在关闭时也会提示，已保存报告保留。

### v0.2.56 维护与恢复

- 在图像与数据打开「报告任务与分步重试」或「缓存与导出文件」。Ctrl+F 搜索，Esc 清空当前搜索框，F5 刷新。再次打开同一工具会返回原窗口，保留搜索与选择；刷新用真实文件身份保留选择。
- 报告列表默认只看未完成项，可切换全部报告。选中后下方显示分步状态和错误；可复制详情、打开复盘或记录目录。多选重试时跳过已完成报告，逐项结果进入批量任务窗口；单场错误不会中断其余场次，等待内存也保留为未完成。
- 缓存清理只允许有占用的可重建项目；混选原始赛事或用户导出内容时禁用清理。确认窗口列出本次目标，清理后显示释放空间。清理或报告重试中须等待离线维护完成再启动记录；读取列表不限制启动。
- 检查疑似拆分时，选择一组查看前段和后段。「标为已检查」后定位下一组；「撤销最近标记」恢复最近一次检查标记。本次运行保留最近 20 次撤销机会，关闭并重开检查窗口仍可用，退出程序后撤销历史不保留。标记不会合并、删除或改写原始赛事。

### v0.2.57 车型阈值和圈 A/B

- 在「采样与遥测 → 车型轮胎阈值」选择车型。清单包含已有记录和已保存配置中的车型。`*` 是未单独设置车型的通用默认，提示会说明当前值是否来自车型专属配置。
- 「保存并继续」或 Ctrl+S 仅保存当前车型并保留窗口；「撤销本次修改」恢复已保存值。「载入通用默认」复制到当前草稿，仍需保存才生效；选择 `*` 时则可载入内置默认。关闭或 Esc 会保护未保存修改。从参数搜索打开的目标字段自动滚动到可见位置。
- 圈 A/B 选择器已打开时，在主列表选择新赛事并再次点「圈 A / 圈 B 选择器」，会复用原窗口、只更新相应一侧；仅选一场时保留 B。筛选条件和未改动侧的圈号保留。新出现的赛事会触发后台更新清单。
- 生成对比期间所有赛事及圈号选择锁定，避免画面选择与正在生成的结果不一致。生成结束可继续编辑，或用「打开上次对比」重开最近一次成功生成的文件；它不会重建对比，也不会因当前选择变化而改指其他结果。文件被移动或删除时需重新生成。

### v0.2.58 战绩卡预览与导出

- 在个人赛道记录或领奖台记录选择纪录后，打开「生成个人战绩卡」。同一纪录再次点击会返回已有窗口，保留本次姓名／日期显示选项；新的窗口仍默认隐藏这两项。
- 修改分享设置后，当前预览会保留到新版就绪。导出按钮在最新预览准备好后启用；正在更新或预览失败时，不能误导出旧版。读取或绘制出错可用「重试读取 / 预览」恢复。
- 「生成并打开图片」或 Ctrl+S 保存当前完整分辨率预览。导出期间隐私开关和生成按钮暂时禁用；已经导出的文件独立保存，不覆盖旧卡。
- 保存后可在底部复制最近保存路径，或直接「打开上次图片」「打开导出目录」。查看器打开失败并不表示保存失败，可直接重试打开。文件被移动或删除时会明确提示。
- 关闭战绩卡窗口不会取消已经提交的导出；完成后主界面状态会显示文件位置。程序正常退出也会等待已提交写入完成。
- 深浅主题均可使用。较小窗口中，右侧设置独立滚动、底部按钮按宽度换行。切换语言会更新预览；已开始的导出仍保存提交时看到的那一版，底部会说明当前预览是否已经更新。


### v0.2.59 快速阅读报告图片

在赛事复盘列表、领奖台详情或最近赛事点击圈速单 / 赛事日志，会复用内置图片窗口。已有文件直接打开保存版本；首次缺少图片时显示后台生成进度，不需要反复点击。没有完成圈时圈速单可能不存在，可切换赛事日志。

默认按宽度显示长图。滚轮上下浏览，Shift+滚轮横向浏览，Ctrl+滚轮以指针位置缩放，鼠标拖动平移；左右方向键切换两类报告。Home / End 跳到首尾，Page Up / Page Down 翻页，F 适应宽度，0 适应整图，1 原始比例，+ / - 缩放，F5 重新读取，Esc 关闭。窗口保持打开时，切换回来会恢复该图的阅读位置。

「系统查看器」打开当前 PNG 原文件，「赛事目录」可查看其他附件或分页文件。「重新读取」刷新当前保存的图片，不生成报告。「重新生成图片」用于应用新的报告配置或修复缺失内容，执行前将现有主要报告备份到该场的 `_report_history`；生成失败后旧报告和原始遥测仍保留。正常退出应用会等待已提交的生成任务完成。

原始 PNG 不会因查看、缩放或主题切换而被压缩、缩小或重写。深浅主题影响查看器界面，报告图片保持生成时的样式。


### v0.2.60 连续分析与报告导出

个人赛道纪录中的「训练优先级报告」「同条件进步分析」对同一纪录复用已有窗口。需要读取新赛事时点击重新分析或按 F5；反复打开窗口不会丢弃本次输入。不同纪录的窗口独立。

同条件分析的「编辑分析条件」展开六项容差；修改后点击「应用条件并分析」。条件错误会展开并定位字段；既有范围和稳定性最低圈数要求不变。「分析范围」的三项开关仅用于探索，混合样本仍不构成可靠提升结论。训练优先级的范围开关会自动分析，并合并连续改动。

分析中、条件未应用或分析失败时，已有图表保持可看，导出和依赖当前结果的操作暂不可用。修正后重新分析即可恢复。连续提交仅保留最新请求；已提交的新条件在关闭时继续处理，正常退出会等待已提交任务。仅有未提交的修改时，关闭和退出会要求继续编辑或明确放弃。

就绪后 Ctrl+S 或导出按钮保存当前结果。保存期间锁定条件；保存路径可复制，可直接重开上次报告或所在目录。浏览器打开失败不必再次导出；关闭窗口不会取消已提交的报告写入，完成路径会显示在主界面。

训练目标建立期间不能重复提交；同一次分析中已经建立目标的区间会禁用建立按钮，可在查看训练目标中继续跟进。重新分析后可按新参考结果建立新目标。

分析窗口的列表没有溢出或已到滚动边界时，滚轮会继续滚动正文；长列表内部仍独立滚动，Shift+滚轮保留横向浏览。
