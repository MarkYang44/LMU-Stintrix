# 数据处理流程与性能边界

数据质量优先：不减少采样、不转 float32、不添加新的舍入或插值、不重编码视频，不迁移或改写历史赛事。保留完整样本、原始 CSV 字段、时间戳、缺失值和已有计算规则。所有性能数字都限定到实际测量的环节。

| 环节 | 检查结果与处理方式 |
| --- | --- |
| 实时采集与保存 | 保留有界后台队列、批量写盘、完整收尾及 fsync 检查点；不通过丢样、延迟落盘或降低频率提速。 |
| CSV／列式数据读取 | 保留透明读取、字段投影和原 CSV 优先规则；临时 float64 表改为顺序分块读取，随机访问仍有独立有界缓存。 |
| 官方 DuckDB 导入 | 已按通道分批读取，保持时间顺序、重复时间点规则和源文件前后检查；只读连接及隔离限制保留。 |
| 圈分析与稳定参考 | 正常情况下复用最近五圈的原始临时数据；动作指标合并单次遍历，条件一次提取；歧义重复圈号继续采用历史回退路径。 |
| 训练与进步分析 | 赛后分析复用原始完整曲线生成原格式训练缓存；首次训练不再重复解析整场。缓存缺失或可选准备失败时仍可自行计算，继续执行条件及最低样本检查。 |
| 最快圈与复盘 | 同一赛后任务共用已验证的最快圈、全采样曲线、条件和车辆数据，减少全场扫描及重复解析；独立打开或重试缺失步骤时仍可自行读取。 |
| 耐力与天气 | 保留原单次顺序读取、进站边界、间隙及条件未知的处理，不减少通道或用估算替代缺失字段。 |
| 数字 JSON／HTML | 小型纯数字行使用标准 JSON 编码器快速路径；大行回退到分块编码。保持全精度、Unicode、空值和非有限数检查。 |
| 图片生成 | 继续按来源、渲染器及素材状态复用结果；保留外部生成器、图片规格、原素材和内存门限。未更改第三方生成器。 |
| 无损压缩 | 完全相同的常量列编码复用不可变字节；其他列仍计算原有候选并选择最短。容器格式、压缩级别和结果字节保持一致。 |
| 归档、CSV 与独立 HTML 导出 | 已有流式输出、导出复用、原子发布及文件变化检查，继续保留路径、链接、大小、CRC 和可选完整检查。 |
| 视频分析 | 已按裁剪区域流式解码并保留真实 PTS；不降低用户采样率或 OCR 配置，不制造恒定帧率时间戳。 |
| 后台调度与重试 | 保留独立报告进程、内存不足延后、分步骤就绪状态；成功步骤不重复处理，失败步骤仍可重试。 |

## 共用数据的范围

`processing_context` 只覆盖一次已结束赛事的处理任务，按实际来源文件的物理状态检查数据。不同赛事、其他线程和下一次任务不继承旧数据。结束或异常时清空引用。最多保留最近五圈和一圈最快圈所需的磁盘临时数据，不将整场浮点矩阵装入 Python 对象列表。

临时数值表的随机访问缓存最多两页；顺序迭代器各保留约 64 KiB 数值块，UTC 迭代另保留一块文字缓冲，超长单条时间文本按原长度读取。常量列编码缓存最多 128 项，仅缓存每值不超过 256 字节、至多 2048 行的常量列。缓存没有改变原始数据或增加持久化用户设置。

## v0.2.80 任意圈与网页对比

有效圈完整校验之后，保存来源绑定的圈清单、原 CSV 文本位置和行范围；列式来源按原有块索引读取。文本位置使用 Python CSV 与通用换行读取，兼容 Unicode、引号和多行字段，不按换行符猜测记录边界。轮胎文字仍采用原来的首个时间匹配，避免游戏圈号延迟造成条件差异。时间重置时保留旧 CSV 导出扫描路径。

正常赛后分析在同次全量读取中建立索引，既保留分析对无效／进站圈的排除，也保留选择器对结构完整性和有效性标记的独立处理。旧赛事只在实际选择时建立，不批量迁移历史数据。单份落盘索引不超过 4 MiB；来源使用物理文件大小、纳秒时间与文件身份，索引内容另校验摘要。源文件、版本变化或摘要损坏时重新扫描；只读目录保存失败时继续普通提取。

单圈 JSON／CSV 导出按来源、应用版本与输出状态复用。更换组合时只处理未知圈，已处理圈的文件不重写；布局校验继续使用原始未舍入圈长。来源校验覆盖实际 CSV 和 `.stc`，避免逻辑 CSV 时间戳不变时误用旧结果。本机索引不含整场采样，也不进入 ZIP／7z 比赛归档、源码或发布包。

网页 12 m 全油恢复窗口采用单次遍历，边界包含关系与原版一致；逐弯表格和建议共用结果，原始／过滤通道、基准圈和弯段变化时失效。

同一约 102 MB 输入、27 MB 车辆数据样本，与 v0.2.79 对比：

## v0.3.1 公共流程与分析

此次覆盖公共读取层、正常赛后分析、稳定参考、训练与进步分析、官方导入、复盘输出及无损编码。采集与保存已经有有界队列、批量写盘和完整收尾；图片、视频和归档保留现有来源复用、ROI／PTS 及完整性检查，不为缩短耗时降低规格或取消保护。

- 临时表连续切片和时间列顺序分块读取，不再逐行随机访问；倒序、跨步及嵌套随机读取保持原语义。
- 原始与过滤输入的动作指标、ABS／TC 时长和输入差异合并一次遍历。去抖、缺口、阈值、求和次序及原有中位数计算保留。
- 固定布局条件通道排除不存在的列，一次读取各通道首个实际值；官方原生通道的覆盖规则不变。
- 原 CSV 按所需字段直接投影，保留重复列名、缺失字段、空值及多行文本的标准 CSV 语义；无引号字段按字节快速拆分，含引号内容继续原路径。
- 正常赛后分析在已有曲线基础上生成相同的 601 点训练资料及完整观察特征。这是原有训练格式，未减少源采样或改变报告分析精度；完整原始曲线仍保留。缓存按圈写入，受既有容量与活动引用保护；错误时由原训练入口重新生成，不影响主要报告。
- 退役为 `.stc` 的训练来源检查实际文件身份与纳秒时间，避免逻辑 CSV 时间未变时错误复用。
- 官方通道网页采用二分定位可见区间及原先的绘图边缘余量，保留区间内全部采样、重复时间点和缺口断线规则。
